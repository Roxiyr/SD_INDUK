# SD Induk

Proyek ini berisi aplikasi frontend React dengan Vite. Folder `backend` saat ini belum berisi file.

## Menjalankan frontend

```powershell
cd frontend
npm install
npm run dev
```

## Perintah yang tersedia

Jalankan dari folder `frontend`:

```powershell
npm run build
npm run lint
npm run preview
```
