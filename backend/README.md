# Backend Buku Induk Siswa SD

Struktur awal backend berada di `src`:

```text
src/
├── config/       # Konfigurasi aplikasi
├── controllers/  # Penanganan request dan response
├── middlewares/  # Middleware request
├── models/       # Model dan struktur data
├── routes/       # Definisi endpoint
├── services/     # Logika bisnis
└── utils/        # Fungsi bantu
```

Folder akan diisi saat teknologi backend dan fitur API mulai ditentukan.
